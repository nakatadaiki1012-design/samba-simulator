# サンバ・シミュレーター

サンバやラテン音楽のリズムが「どんな楽器の組み合わせでできているか」を、音を聴きながら学べるWebアプリです。

## できること

0. **3Dステージ** … 関節のある3Dの演奏者が音に合わせて楽器を叩きます。サンバでは「カーニバル」ボタンで、リオの街を練り歩く「ブロコ」（カラフルな建物、白黒の波模様の石畳、旗飾り、見物人、後ろで踊る人たち、指揮者の笛つき）に切り替わります。演奏者をタップすると、カメラが寄って「リズム」と「楽器を知る」（原語名・生まれ・材料・大きさ・演奏法・豆知識・音の試し鳴らし）が見られます。1画面で完結します。
1. **サンバを組み立てる** … スルド（低い太鼓）から順番に楽器を1つずつ重ね、9ステップでサンバの打楽器隊（バテリア）を完成させます。マスをタップしてリズムを書きかえたり、「ランダムに生成」で新しい組み合わせを作れます。
2. **ラテン音楽を比べる** … サンバ、ボサノバ、ソン、マンボ、チャチャチャ、ルンバ（キューバ／社交ダンス）、サルサ、メレンゲ、クンビア、タンゴ、レゲトンの12ジャンルを、実際に鳴らしながら比較。クラーベの解説、家系図、比較表つき。
3. **聴き分けクイズ** … 流れるリズムがどのジャンルか当てるクイズ。

## 使い方

`index.html` をダブルクリックしてブラウザ（Chrome / Safari / Edge など）で開くだけです。インストールは不要です。

インターネットで公開したい場合は、GitHub のリポジトリ設定 → **Pages** → 「Branch」で公開したいブランチを選んで保存すると、URL でアクセスできるようになります。

## メモ

- 楽器の音は録音サンプル（`sounds.js`）に、響き（リバーブ）・左右の配置・人間らしいタイミングのゆれを加えて鳴らしています。サンプルを読み込めない場合は、ブラウザ内の合成音で鳴ります。
- `index.html` と `sounds.js` は同じフォルダに置いてください。
- 3D表示にはインターネット接続が必要です（Three.js を読み込むため）。
- スマートフォンで音が出ないときは、マナーモードを解除してください。
- リズムは学習用に簡略化しています。

## 音源のクレジット

`sounds.js` の録音サンプルは、FluidR3_GM サウンドフォント（Frank Wen 作、MIT License）を MP3 化した npm パッケージ [soundfont-for-samplers](https://www.npmjs.com/package/soundfont-for-samplers)（MIT License）から、必要な音だけを短く切り出したものです。
